# diagram

A **diagram** in a [category](./category.md) $\mathcal C$ consists of some
[objects](./category.md) of $\mathcal C$ connected by some
[morphisms](./category.md) of $\mathcal C$.[^1]

## with functors

If $\mathcal C$ is a category and $\mathcal J$ is a small category, a diagram of type $\mathcal J$ in $\mathcal C$
is a covariant [functor](./functor.md) $F\colon \mathcal J \to \mathcal C$.[^1] [^2]

[^1]: https://ncatlab.org/nlab/show/diagram
[^2]: https://en.wikipedia.org/wiki/Functor
